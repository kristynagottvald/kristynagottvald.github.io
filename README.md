# Kristyna Gottvald — Brand Design Portfolio

Portfolio site for Kristyna Gottvald, a multidisciplinary brand designer and AI-native builder working with growth-stage B2B SaaS teams.

**Live site:** https://kristynagottvald.github.io

## About

A static, single-page portfolio with no build step and no framework. It includes case studies, a projects index, an About page, and interactive generative sketches built with creative code.

## Structure

- `index.html`: page shell (home, case study, projects, and about views)
- `script.js`: hash-based routing and rendering
- `styles.css`: all styles
- `projects.json`: case study content and metadata
- `*-sketch.html`: standalone interactive sketches embedded in case studies
- Images (`.webp`, `.png`, `.gif`) live at the repo root
